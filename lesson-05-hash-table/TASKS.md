# Практическое задание к Уроку 5

## Цель работы
Понять принцип работы хеш-таблицы, реализовать метод цепочек для разрешения коллизий и на практике убедиться в преимуществе хеш-таблицы (O(1)) над линейным поиском в массиве (O(n)).

## Что нужно сделать

### Часть 1. Собственная реализация хеш-таблицы
Откройте `src/custom_hash_table.cpp`. Ваша задача — реализовать базовые операции:
1. **Хеш-функция:** используйте простую функцию для преобразования ключа в индекс.
2. **Вставка (`insert`):** вычислить хеш, перейти в нужную корзину и добавить элемент.
3. **Поиск (`find`):** вычислить хеш и найти элемент в корзине.

*Проверка:* Запустите программу. Убедитесь, что после добавления элементов вы можете найти их по ключу.

### Часть 2. Решение практической задачи (стандартная хеш-таблица)
Откройте `src/stl_hash_table.cpp`. 
**Задача:** Подсчитать частоту слов в заданном тексте.
1. Считать строку (например, "яблоко банан яблоко апельсин яблоко").
2. Разбить её на слова.
3. Используя `std::unordered_map<std::string, int>`, посчитать, сколько раз встречается каждое слово.
4. Вывести результат.

*Проверка:* Запустите программу. Для строки выше результат должен быть: яблоко: 3, банан: 1, апельсин: 1.

### Часть 3. Бенчмарк (Хеш-таблица против Вектора)
Откройте `src/benchmark_hash.cpp`. Программа:
1. Заполняет `std::vector<int>` 100 000 элементами.
2. Замеряет время поиска элемента (которого нет в массиве) с помощью `std::find` (линейный поиск, O(n)).
3. Заполняет `std::unordered_map<int, int>` теми же 100 000 элементами.
4. Замеряет время поиска элемента с помощью `map.find` (O(1)).

Запустите программу и сравните результаты.

**Ожидаемый результат:** Поиск в хеш-таблице работает в тысячи раз быстрее (микросекунды против миллисекунд), так как хеш-таблица сразу вычисляет индекс, а вектор перебирает все элементы.
**Вывод:** Для задач, где требуется частый поиск по ключу (проверка уникальности, словари, кэши), необходимо использовать хеш-таблицы (`std::unordered_map` или `std::unordered_set`).

### Часть 4. Инженерный итог
Сформулируйте правило выбора:
* **Поиск по ключу:** используйте `std::unordered_map` (или `std::unordered_set`). Это O(1).
* **Поиск в массиве:** используйте линейный поиск (`std::find`) только для маленьких массивов или когда нет возможности использовать хеш-таблицу.
