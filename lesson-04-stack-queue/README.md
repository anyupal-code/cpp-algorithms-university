## Теория

### 1. Эффективность обработки данных в порядке
Часто задачи требуют обработки данных в обратном порядке (как в стеке) или в порядке поступления (как в очереди). Применение правильной структуры данных позволяет выполнять эти операции за O(1). Использование массивов или векторов приводит к затратам O(n) из-за сдвига элементов, что критически замедляет обработку больших объемов данных.

### 2. Стек и Очередь: принципы и операции

**Стек (Stack)** работает по принципу **LIFO** (Last In, First Out) — «последним пришел, первым вышел». Пример: стопка тарелок (кладем и берем сверху).

**Очередь (Queue)** работает по принципу **FIFO** (First In, First Out) — «первым пришел, первым вышел». Пример: очередь в магазине.

| Операция | Стек (Stack) | Очередь (Queue) |
| :--- | :--- | :--- |
| **Добавление** | `push` (на вершину) | `push` (в конец) |
| **Удаление** | `pop` (с вершины) | `pop` (из начала) |
| **Просмотр** | `top` (вершина) | `front` (первый элемент) |
| **Сложность** | O(1) | O(1) |

### 3. Инженерный вывод: что использовать?
* **Для стека используйте `std::vector`**. Все операции происходят с конца. Вектор хранит данные непрерывно, поэтому процессор эффективно их кэширует.
* **Для очереди используйте `std::deque`**. Стандартная `std::queue` использует его под капотом. `std::deque` позволяет удалять из начала за O(1) без сдвига элементов. Вектор для очереди не подходит, так как `erase(begin())` работает за O(n).

### 4. Применение в разработке
* **Стек:** Отмена действий (Ctrl+Z), проверка правильности скобок в коде (парсинг), обход в глубину (DFS) в графах.
* **Очередь:** Обработка сетевых пакетов, планировщик задач в ОС, обход в ширину (BFS) в графах, буферизация данных при печати.

### 5. Базовый синтаксис (std::stack и std::queue)
~~~cpp
#include <stack>
#include <queue>

std::stack<int> s;
s.push(10);
s.push(20);
int top = s.top(); // 20
s.pop(); // Удалили 20

std::queue<int> q;
q.push(10);
q.push(20);
int front = q.front(); // 10
q.pop(); // Удалили 10
~~~

Выполните задания из [TASKS.md](TASKS.md), чтобы получить практические результаты.

### Предполагаемые результаты бенчмарков

**Стек (Вектор vs Список):**
Стек на основе `std::vector` работает в несколько раз быстрее, чем на основе `std::list`.
*Вывод:* данные в векторе хранятся непрерывно, поэтому процессор эффективно их кэширует. Для стека используйте `std::vector`.

**Очередь (Deque vs Вектор):**
Очередь на основе `std::deque` работает мгновенно, а очередь на векторе (с удалением из начала через `erase`) — крайне медленно.
*Вывод:* удаление из начала вектора требует сдвига всех элементов (O(n)), а `std::deque` делает это за O(1). Для очереди используйте `std::deque` (или стандартный `std::queue`).
