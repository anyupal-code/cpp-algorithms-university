# Практическое задание к Уроку 6

## Цель работы
Понять принцип работы бинарного дерева поиска (BST), реализовать вставку и поиск, а также на практике сравнить скорость поиска в BST с линейным поиском в массиве.

## Что нужно сделать

### Часть 1. Собственная реализация BST
Откройте `src/custom_bst.cpp`. Ваша задача — реализовать методы:
1. **Вставка (`insert`)** — добавление нового узла в дерево с соблюдением свойств BST (левый потомок меньше, правый больше).
2. **Поиск (`search`)** — нахождение узла по значению.
3. **Симметричный обход (`inorder`)** — вывод элементов в отсортированном порядке (Левый -> Узел -> Правый).

*Проверка:* Запустите программу. Убедитесь, что после вставки элементов дерево выводит их в отсортированном порядке.

### Часть 2. Решение практической задачи (стандартные контейнеры)
Откройте `src/stl_set_map.cpp`. 
**Задача 1 (set):** Дан список слов с повторениями. Используя `std::set`, выведите только уникальные слова в алфавитном порядке.
**Задача 2 (map):** Используя `std::map`, сохраните оценки студентов и выведите их, отсортировав по именам.

*Проверка:* Запустите программу. Убедитесь, что слова выводятся без дубликатов, а студенты — по алфавиту.

### Часть 3. Бенчмарк (BST против Вектора)
Откройте `src/benchmark_bst.cpp`. Программа:
1. Заполняет `std::vector<int>` 100 000 элементами.
2. Замеряет время поиска элемента с помощью `std::find` (линейный поиск, O(n)).
3. Заполняет `std::set<int>` теми же элементами.
4. Замеряет время поиска элемента с помощью `set.find` (древовидный поиск, O(log n)).

Запустите программу и сравните результаты.

**Ожидаемый результат:** Поиск в `std::set` работает в разы быстрее, чем в векторе, так как дерево отсекает половину оставшихся элементов на каждом шаге.
**Вывод:** Для задач, где требуется быстрый поиск с сохранением отсортированного порядка, используйте `std::set` или `std::map`.

### Часть 4. Инженерный итог
Сформулируйте правило выбора:
* **Нужен быстрый поиск и порядок:** `std::set` / `std::map` (O(log n)).
* **Нужен максимально быстрый поиск и порядок не важен:** `std::unordered_set` / `std::unordered_map` (O(1)).
* **Нужен простой перебор без поиска:** `std::vector`.
