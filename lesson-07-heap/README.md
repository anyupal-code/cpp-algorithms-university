## Теория

### 1. Зачем нужна куча?
Представьте, что вам нужно постоянно получать **самый важный** (или самый большой) элемент из постоянно обновляющегося набора данных. 
* Если использовать неотсортированный массив — поиск максимума занимает O(n).
* Если использовать отсортированный массив — вставка нового элемента занимает O(n).
* Если использовать кучу — и вставка, и извлечение максимума занимают **O(log n)**.

### 2. Свойства кучи
Куча — это бинарное дерево, которое хранится в массиве (без указателей) и обладает двумя свойствами:
1. **Свойство кучи (Max-Heap):** Значение родителя всегда больше или равно значениям его потомков. (В Min-Heap — наоборот, родитель меньше).
2. **Полнота:** Все уровни дерева, кроме последнего, заполнены полностью, а последний уровень заполняется слева направо.

**Связь индексов в массиве:**
* Родитель: `(i - 1) / 2`
* Левый потомок: `2 * i + 1`
* Правый потомок: `2 * i + 2`

### 3. Основные операции
* **Вставка (`push`):** Новый элемент добавляется в конец массива. Затем он «всплывает» (sift up) вверх, меняясь местами с родителем, пока не встанет на свое место. O(log n).
* **Извлечение максимума (`pop`):** Корень (максимум) удаляется. Последний элемент массива ставится на место корня и «проседает» (sift down) вниз, меняясь местами с большим из потомков. O(log n).
* **Просмотр максимума (`top`):** Просто посмотреть на корень (индекс 0). O(1).

### 4. Инженерный вывод: когда использовать?
* **Куча (Priority Queue):** когда нужно многократно извлекать элемент с наивысшим приоритетом (максимум или минимум), а порядок остальных элементов не важен.
* **Сортировка:** Пирамидальная сортировка (Heap Sort) использует кучу для сортировки массива за O(n log n).
* **Алгоритмы на графах:** Алгоритм Дейкстры использует приоритетную очередь для поиска кратчайшего пути.

### 5. Применение в разработке
* **Планировщики задач (ОС):** Выбор задачи с наивысшим приоритетом.
* **Обработка событий:** Обработка событий в хронологическом порядке.
* **Кодирование Хаффмана:** Сжатие данных (построение дерева на основе частот).

### 6. Базовый синтаксис (std::priority_queue)
В C++ стандартная куча — это `std::priority_queue`. По умолчанию она является Max-Heap (на вершине самый большой элемент).
~~~cpp
#include <queue>

std::priority_queue<int> pq;
pq.push(10);
pq.push(30);
pq.push(20);

int max = pq.top(); // 30
pq.pop(); // Удалили 30
~~~

Чтобы сделать Min-Heap (на вершине самый маленький элемент), нужно использовать `std::greater`:
~~~cpp
std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;
~~~

## Практика

В папке `src/` находятся три файла:
* `custom_heap.cpp` — заготовка для **собственной реализации** кучи (Max-Heap).
* `stl_priority_queue.cpp` — пример решения практической задачи с использованием `std::priority_queue`.
* `benchmark_heap.cpp` — замер скорости: **извлечение максимума из кучи против линейного поиска в векторе**.

Выполните задания из [TASKS.md](TASKS.md), чтобы получить практические результаты.

### Предполагаемые результаты бенчмарков
Извлечение максимума из кучи (O(log n)) будет значительно быстрее, чем поиск максимума в неотсортированном массиве (O(n)), особенно если операция повторяется многократно.
*Вывод:* для задач, где нужно часто находить максимальный (или минимальный) элемент, используйте `std::priority_queue` (кучу).
