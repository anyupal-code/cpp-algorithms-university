## Теория

### 1. Зачем нужен алгоритм Дейкстры?
В прошлом уроке мы использовали BFS для поиска кратчайшего пути в **невзвешенном** графе (где каждое ребро имеет одинаковую "стоимость").
Но в реальной жизни дороги имеют разную длину, а сетевые пакеты — разную задержку. Если у ребер есть **вес** (стоимость), BFS не подходит. Здесь на помощь приходит алгоритм Дейкстры.

### 2. Как работает алгоритм Дейкстры
1. Задаем всем вершинам бесконечное расстояние (кроме стартовой — у нее 0).
2. Выбираем непосещенную вершину с наименьшим расстоянием (используем **приоритетную очередь** или `std::set`).
3. Для всех ее соседей проверяем: если путь через текущую вершину короче, чем известный, — обновляем расстояние.
4. Помечаем текущую вершину как посещенную.
5. Повторяем, пока не дойдем до цели или не кончатся вершины.

### 3. Сложность
С использованием приоритетной очереди (кучи) сложность алгоритма Дейкстры составляет **O(E log V)**, где E — количество ребер, V — количество вершин. Это очень быстро.

**Ограничение:** алгоритм Дейкстры не работает с **отрицательными весами** (для этого используется алгоритм Беллмана-Форда).

### 4. Инженерный вывод: когда использовать?
* **Дейкстра:** поиск кратчайшего пути во взвешенном графе без отрицательных весов (навигация, маршрутизация).
* **BFS:** поиск кратчайшего пути в невзвешенном графе (лабиринты, социальные сети).
* **Беллман-Форд:** если в графе есть отрицательные веса (например, финансовые транзакции с убытками).

### 5. Применение в разработке
* **Навигаторы:** построение маршрута с учетом пробок (вес ребра = время в пути).
* **Сетевые протоколы:** OSPF (маршрутизация пакетов).
* **Логистика:** поиск самого дешевого пути доставки.

### 6. Базовый синтаксис (std::priority_queue)
Для эффективного поиска вершины с минимальным расстоянием используется min-куча:
~~~cpp
#include <queue>
#include <vector>

// Минимальная приоритетная очередь (по расстоянию)
std::priority_queue<
    std::pair<int, int>, 
    std::vector<std::pair<int, int>>, 
    std::greater<std::pair<int, int>>
> pq;
~~~

## Практика

В папке `src/` находятся три файла:
* `custom_dijkstra.cpp` — заготовка для **собственной реализации** алгоритма Дейкстры.
* `stl_dijkstra.cpp` — пример решения практической задачи (поиск маршрута в городе).
* `benchmark_dijkstra.cpp` — замер скорости: **Дейкстра против полного перебора (DFS)**.

Выполните задания из [TASKS.md](TASKS.md), чтобы получить практические результаты.

### Предполагаемые результаты бенчмарков
На графе с 1000 вершинами и 5000 ребрами:
* Полный перебор (DFS) всех путей для поиска кратчайшего займет много времени (экспоненциально).
* Дейкстра найдет путь за доли секунды (O(E log V)).
*Разница в производительности будет колоссальной.*
