# Практическое задание к Уроку 11

## Цель работы
Изучить алгоритм Дейкстры, реализовать поиск кратчайшего пути во взвешенном графе с помощью приоритетной очереди и на практике убедиться, что он работает значительно быстрее полного перебора.

## Что нужно сделать

### Часть 1. Собственная реализация Дейкстры
Откройте `src/custom_dijkstra.cpp`. Ваша задача — реализовать алгоритм Дейкстры для графа, представленного списком смежности с весами.
1. Создайте массив `dist` для хранения минимальных расстояний (изначально `INF`).
2. Используйте `std::priority_queue` для выбора вершины с наименьшим расстоянием.
3. Для каждого соседа проверяйте: если `dist[current] + weight < dist[neighbor]`, обновляйте расстояние и добавляйте соседа в очередь.

*Проверка:* Запустите программу. Она должна вывести кратчайшее расстояние от вершины 0 до всех остальных.

### Часть 2. Решение практической задачи (поиск маршрута)
Откройте `src/stl_dijkstra.cpp`. 
**Задача:** Дан граф городов с расстояниями между ними. Найдите кратчайший маршрут от города A до города D. Выведите не только расстояние, но и сам маршрут (последовательность городов).
*Подсказка:* используйте массив `parent`, чтобы запоминать, из какой вершины вы пришли в текущую.

*Проверка:* Запустите программу. Убедитесь, что выводится корректный путь (например, A -> B -> D) и его длина.

### Часть 3. Бенчмарк (Дейкстра против DFS)
Откройте `src/benchmark_dijkstra.cpp`. Программа создает случайный взвешенный граф из 100 вершин и замеряет время поиска кратчайшего пути с помощью Дейкстры. Для сравнения запускается полный перебор (DFS), который находит путь, но не обязательно кратчайший (и работает намного дольше).

**Ожидаемый результат:** Дейкстра находит оптимальный путь за микросекунды, в то время как DFS может исследовать огромное количество путей.
**Вывод:** Для поиска кратчайшего пути во взвешенном графе используйте алгоритм Дейкстры с приоритетной очередью.

### Часть 4. Инженерный итог
Сформулируйте правило выбора:
* **Взвешенный граф без отрицательных весов:** Дейкстра (O(E log V)).
* **Невзвешенный граф:** BFS (O(V + E)).
* **Граф с отрицательными весами:** Беллман-Форд.
