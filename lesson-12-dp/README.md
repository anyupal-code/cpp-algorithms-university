## Теория

### 1. Проблема наивной рекурсии
Многие задачи можно разбить на подзадачи. Например, чтобы найти 10-е число Фибоначчи, нужно знать 9-е и 8-е. Но если считать наивно, то 8-е число будет вычисляться дважды (для 9-го и для 10-го), 7-е — трижды и т.д. Сложность такого алгоритма — **O(2^n)**, что катастрофически медленно.

### 2. Что такое динамическое программирование?
Динамическое программирование (ДП) — это метод решения задач путем разбиения на подзадачи и **сохранения результатов** этих подзадач, чтобы не вычислять их повторно.

**Два подхода:**
1. **Мемоизация (сверху вниз):** пишем обычную рекурсию, но сохраняем результаты в массив/таблицу. Если значение уже есть — берем его оттуда.
2. **Табуляция (снизу вверх):** создаем массив и заполняем его последовательно, начиная с базовых случаев (например, `dp[0] = 0`, `dp[1] = 1`, затем `dp[i] = dp[i-1] + dp[i-2]`).

### 3. Сложность
ДП позволяет снизить сложность с **O(2^n)** до **O(n)** (если состояние зависит от одного параметра) или до **O(n * m)** (если от двух).

### 4. Инженерный вывод: когда использовать ДП?
* Задача разбивается на подзадачи, которые пересекаются (одни и те же подзадачи решаются многократно).
* Есть **оптимальная подструктура** (оптимальное решение задачи содержит оптимальные решения подзадач).
* Примеры: числа Фибоначчи, задача о рюкзаке, поиск наибольшей общей подпоследовательности, редактирование текста (расстояние Левенштейна).

### 5. Применение в разработке
* **Биоинформатика:** выравнивание последовательностей ДНК.
* **Финансы:** оптимизация портфеля, расчет рисков.
* **Сжатие данных:** алгоритмы сжатия (LZW).
* **Искусственный интеллект:** обучение с подкреплением (Q-learning).

## Практика

В папке `src/` находятся три файла:
* `custom_dp.cpp` — заготовка для **собственной реализации** мемоизации (на примере чисел Фибоначчи).
* `stl_dp.cpp` — пример решения практической задачи (задача о рюкзаке) с использованием табуляции.
* `benchmark_dp.cpp` — замер скорости: **наивная рекурсия против ДП**.

Выполните задания из [TASKS.md](TASKS.md), чтобы получить практические результаты.

### Предполагаемые результаты бенчмарков
Для 40-го числа Фибоначчи:
* Наивная рекурсия работает секунды (или минуты).
* ДП с мемоизацией работает за микросекунды.
*Разница в производительности колоссальная.*
