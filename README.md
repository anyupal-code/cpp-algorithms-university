# Алгоритмы и структуры данных на C++

Курс по алгоритмам и структурам данных на языке C++. 
Цель курса — освоение методов построения эффективных алгоритмов, изучение внутреннего устройства структур данных и получение практических навыков написания быстрого и оптимизированного кода.

Курс построен по принципу «от простого к сложному»: от базовых структур (вектор, список) до сложных алгоритмов на графах и динамического программирования.

---

## Чему вы научитесь

* Оценивать временную и пространственную сложность алгоритмов (Big O).
* Понимать внутреннее устройство базовых структур данных (Vector, List, Stack, Queue).
* Реализовывать структуры данных с нуля (для понимания) и применять стандартные контейнеры STL (для скорости).
* Работать с хеш-таблицами, деревьями поиска и кучами.
* Реализовывать быстрые сортировки (Quick Sort, Merge Sort).
* Обходить графы (DFS, BFS) и находить кратчайшие пути (алгоритм Дейкстры).
* Применять динамическое программирование для решения сложных задач.

## Требования

* **CMake** (система сборки, версия 3.10 или выше).
* **Компилятор C++** (g++ или clang++, поддерживающий стандарт C++17).
* **IDE** (CLion, VS Code) или терминал.
* **Git** (для контроля версий).

---

## Структура репозитория

* `lesson-XX-название/` — папки с материалами каждого урока.
    * `README.md` — теоретический материал, инструкции и чек-лист.
    * `TASKS.md` — практические задания с пошаговыми инструкциями и ожидаемыми результатами.
    * `src/` — исходный код (заготовки для самостоятельной работы, готовые примеры и бенчмарки).
    * `CMakeLists.txt` — файл для сборки конкретного урока.
* `SUMMARY.md` — краткий справочник по всем структурам данным и алгоритмам, а также реальные примеры выбора алгоритмов.

---

## Как проходить курс

1. Изучите теорию в `README.md` текущего урока.
2. Выполните практические задания из `TASKS.md` (сборка через CMake).
3. Запустите бенчмарки, чтобы на практике убедиться в разнице производительности алгоритмов.
4. Сформулируйте инженерный вывод: когда и какую структуру данных использовать.
5. Сделайте коммит после каждого пройденного урока.

---

## Методический подход

1. Сначала разбираем, как алгоритм работает «под капотом».
2. Затем реализуем структуру данных самостоятельно (для понимания).
3. Сравниваем собственную реализацию со стандартной библиотекой (STL).
4. Проводим замеры производительности (бенчмарки), чтобы доказать эффективность правильного выбора алгоритма.
