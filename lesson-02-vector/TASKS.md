# Практическое задание к Уроку 2

## Цель работы
Понять внутреннее устройство динамического массива (на примере собственной реализации) и научиться применять стандартный `std::vector` для решения реальной задачи.

## Что нужно сделать

### Часть 1. Собственная реализация вектора
Откройте `src/custom_vector.cpp`. Ваша задача — дописать метод `push_back`, который:
1. Проверяет, хватает ли памяти (если `size == capacity`).
2. Если нет — выделяет новый массив в 2 раза больше.
3. Копирует старые данные в новый массив.
4. Освобождает старую память.
5. Добавляет новый элемент.

*Проверка:* Запустите программу. Вы должны увидеть, как `capacity` увеличивается (2, 4, 8, 16...). Это демонстрирует, как работает стандартный `std::vector` «под капотом».

### Часть 2. Решение практической задачи (стандартный вектор)
Откройте `src/stl_vector.cpp`. В нем задан список оценок студентов:
~~~cpp
std::vector<int> grades = {5, 4, 3, 5, 4, 2, 5, 4, 3, 4};
~~~

**Задача:** Написать программу, которая:
1. Выводит все оценки.
2. Находит средний балл группы.
3. Находит максимальную и минимальную оценку.
4. Выводит оценки в обратном порядке.

**Важное условие:** Код должен работать с **любым** количеством оценок. Используйте размер вектора `grades.size()` для организации циклов (например, `for (int i = 0; i < grades.size(); i++)`).

### Часть 3. Проверка
1. Запустите `custom_vector` — убедитесь, что ваша реализация вектора работает (расширяет память).
2. Запустите `stl_vector` — убедитесь, что задача с оценками решена правильно.
3. Вручную добавьте в список оценок в `stl_vector.cpp` еще 3 числа. Запустите снова. Убедитесь, что программа пересчитала все автоматически.
