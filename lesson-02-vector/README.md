## Теория

### 1. Вектор в оптимальных алгоритмах

`std::vector` (динамический массив) — базовая структура данных в C++. Быстрый доступ по индексу за O(1) используется для реализации сортировок, бинарного поиска, хеш-таблиц и деревьев.

В практической разработке применяется стандартный `std::vector`. Собственная реализация (`MyVector`) выполняется для изучения алгоритма выделения динамической памяти.

### 2. Ограничения статических массивов

Статический массив в C++ (`int arr[10]`) имеет фиксированный размер. Это ограничение требует ручного управления памятью: при превышении заданного размера приходится создавать новый массив большего размера и копировать в него данные.

### 3. Алгоритм расширения std::vector

`std::vector` — динамический массив, автоматически расширяется при необходимости:
1. Выделяет память под массив.
2. При нехватке места выделяет новый блок памяти в 2 раза больше.
3. Копирует старые данные в новый блок.
4. Удаляет старый блок памяти.

### 4. Ключевые компоненты собственной реализации

Для реализации динамического массива используйте:
* **Указатель на данные** (`int* data`).
* **Текущий размер** — количество занятых элементов (`size`).
* **Вместимость** — количество элементов без расширения (`capacity`).

### 5. Применение std::vector в разработке

Типичные сценарии использования `std::vector`:
1. **Чтение данных из файла (логов):** динамическое добавление строк при неизвестном заранее количестве.
2. **Учет сетевых подключений:** хранение списка активных клиентов, число которых меняется.
3. **Обработка списков данных:** например, оценок студентов, товаров в корзине или результатов измерений.

**Базовый синтаксис:**
* `std::vector<int> vec;` — создание пустого вектора.
* `vec.push_back(10);` — добавление элемента в конец.
* `vec[0] = 5;` — изменение элемента по индексу.
* `vec.size()` — получение количества элементов (длины).
