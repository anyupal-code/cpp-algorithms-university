## Теория

### 1. Зачем нужна сортировка?
Отсортированные данные обрабатываются быстрее. Например, бинарный поиск (O(log n)) работает только на отсортированном массиве. Сортировка также необходима для вывода данных в удобном для человека виде.

### 2. Классификация алгоритмов
Алгоритмы сортировки делятся на две большие группы по сложности:
* **O(n²) — медленные:** Пузырьковая (Bubble Sort), Вставками (Insertion Sort), Выбором (Selection Sort). Подходят только для очень маленьких массивов (до 20-30 элементов).
* **O(n log n) — быстрые:** Быстрая сортировка (Quick Sort), Сортировка слиянием (Merge Sort), Пирамидальная (Heap Sort). Используются в реальных системах.

### 3. Быстрая сортировка (Quick Sort)
Алгоритм «разделяй и властвуй»:
1. Выбирается опорный элемент (pivot).
2. Массив перестраивается так, чтобы элементы меньше опорного оказались слева, а больше — справа.
3. Рекурсивно сортируются левая и правая части.
*Сложность в среднем:* O(n log n).
*Худший случай:* O(n²), если всегда выбирать неудачный опорный элемент. В реальных реализациях используют случайный выбор, чтобы избежать этого.

### 4. Сортировка слиянием (Merge Sort)
Алгоритм «разделяй и властвуй»:
1. Массив делится пополам.
2. Каждая половина сортируется рекурсивно.
3. Отсортированные половины сливаются в один массив.
*Сложность всегда:* O(n log n). Требует O(n) дополнительной памяти.

### 5. Инженерный вывод: когда использовать?
* **Quick Sort:** для сортировки массивов и векторов. Работает на месте (без выделения доп. памяти) и очень быстр на практике.
* **Merge Sort:** для сортировки связных списков (где нет произвольного доступа) или когда важна стабильность сортировки.
* **Стандартная `std::sort`:** использует гибридный алгоритм (Introsort), который сочетает Quick Sort, Heap Sort и Insertion Sort для максимальной производительности.

### 6. Базовый синтаксис (std::sort)
~~~cpp
#include <algorithm>
#include <vector>

std::vector<int> vec = {5, 2, 8, 1};
std::sort(vec.begin(), vec.end()); // Сортировка по возрастанию
~~~

## Практика

В папке `src/` находятся три файла:
* `custom_sort.cpp` — заготовка для реализации **пузырьковой сортировки** (O(n²)) и **Quick Sort** (O(n log n)).

### Предполагаемые результаты бенчмарков
На массиве из 10 000 элементов:
* Пузырьковая сортировка (O(n²)) работает секунды.

*Разница в производительности измеряется в десятки или сотни раз.*
