## Теория

### 1. Ограничения динамического массива (Vector)
`std::vector` обеспечивает быстрый доступ по индексу (O(1)), но вставка или удаление элемента в середину массива требует сдвига всех последующих элементов. В худшем случае это занимает O(n). Если программа часто добавляет или удаляет элементы в середине, вектор становится неэффективным.

### 2. Устройство связного списка
Связный список решает эту проблему. Он состоит из **узлов** (Node). Каждый узел содержит:
1. **Данные** (например, целое число).
2. **Указатель на следующий узел** (`next`).

Элементы списка не лежат в памяти подряд. Они могут быть разбросаны по всей памяти, а связь между ними обеспечивается указателями.

### 3. Преимущества и недостатки
* **Преимущества:** Вставка и удаление элемента в начале или в середине списка занимает O(1) (если у вас есть указатель на нужный узел). Не нужно сдвигать элементы.
* **Недостатки:** Нет доступа по индексу за O(1). Чтобы найти i-й элемент, нужно пройти по списку от начала (O(n)). Дополнительный расход памяти на хранение указателей.

### 4. Виды списков
* **Односвязный (Singly Linked List):** Каждый узел знает только о следующем.
* **Двусвязный (Doubly Linked List):** Каждый узел знает о следующем и предыдущем. Позволяет ходить в обе стороны, но требует больше памяти.

### 5. Применение в разработке
* **История браузера:** Кнопки «Назад» и «Вперед» (двусвязный список).
* **Очереди задач:** Обработка событий в играх или сетевых запросах (FIFO).
* **Хеш-таблицы (разрешение коллизий):** Списки используются для хранения элементов с одинаковым хешем.

### 6. Базовый синтаксис (std::list)
В C++ стандартный двусвязный список — это `std::list`:
* `std::list<int> lst;` — создание пустого списка.
* `lst.push_back(10);` — добавление в конец.
* `lst.push_front(5);` — добавление в начало.
* `lst.remove(10);` — удаление всех элементов со значением 10.

## Практика

В папке `src/` находятся три файла:
* `custom_list.cpp` — заготовка для **собственной реализации** односвязного списка (для изучения указателей).
* `stl_list.cpp` — пример решения практической задачи с использованием **стандартного** `std::list`.
* `benchmark.cpp` — программа для замера скорости вставки в начало (Вектор против Списка).
