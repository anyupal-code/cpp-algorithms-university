# Практическое задание к Уроку 10

## Цель работы
Изучить алгоритмы обхода графа, реализовать DFS (стек) и BFS (очередь) и на практике убедиться, что BFS находит кратчайший путь быстрее, чем DFS.

## Что нужно сделать

### Часть 1. Собственная реализация обходов
Откройте `src/custom_bfs_dfs.cpp`. Ваша задача — дописать функции:
1. **DFS (в глубину)** — использовать `std::stack`. Пройти по графу, посещая все достижимые вершины.
2. **BFS (в ширину)** — использовать `std::queue`. Пройти по графу слоями, записывая расстояние от начальной вершины.

*Проверка:* Запустите программу. Вы должны увидеть порядок обхода вершин для обоих алгоритмов.

### Часть 2. Решение практической задачи (поиск выхода из лабиринта)
Откройте `src/stl_graph.cpp`. Дан двумерный лабиринт (0 — проход, 1 — стена). 
Используя BFS (очередь), найдите кратчайший путь от старта (левый верхний угол) до финиша (правый нижний угол).

*Проверка:* Программа должна вывести длину кратчайшего пути (или сообщение, что пути нет).

### Часть 3. Бенчмарк (BFS против DFS)
Откройте `src/benchmark_graph.cpp`. Программа создает большой лабиринт (100x100) и замеряет время поиска выхода с помощью DFS (который может блуждать) и BFS (который идет по кратчайшему пути).

**Ожидаемый результат:** BFS находит выход значительно быстрее, так как не тратит время на исследование тупиковых веток.
**Вывод:** Для поиска кратчайшего пути всегда используйте BFS. Для проверки связности графа или поиска любого пути можно использовать DFS.

### Часть 4. Инженерный итог
Сформулируйте правило:
* **BFS (очередь):** поиск кратчайшего пути, обход по уровням.
* **DFS (стек):** проверка связности, топологическая сортировка, поиск циклов.
